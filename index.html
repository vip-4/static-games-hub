Lightweight open-source games, playable in any browser

OpenArc is a free, fully static hub of lightweight open-source HTML5 games. Every title runs with plain HTML, CSS and JavaScript — no plugins, no downloads, no backend, no trackers. Play instantly, or self-host the entire catalog on any static host.

What is a lightweight static game?

A lightweight static game is a browser game built from plain HTML, CSS and JavaScript (typically Canvas or WebGL) that requires no installation, no server-side runtime, and no build step to play. Because every asset is a static file, these games load quickly, work offline once cached, and can be hosted for free on GitHub Pages, Netlify, Cloudflare Pages or any object store.

OpenArc collects such games from public open-source sources and publishes them with their original licenses intact, so you can read, modify and redistribute them.

How to self-host OpenArc

  1. Clone or download the repository.
  2. Optionally refresh the catalog: python scripts/fetch-games.py.
  3. Build the deployable folder: python scripts/build.py → dist/.
  4. Upload dist/ to Netlify, Cloudflare Pages or GitHub Pages.
  5. No database, no API keys, no server runtime is required at any step.

Frequently asked questions

What is OpenArc?

OpenArc is a free, static catalog of lightweight open-source HTML5 games that you can play in a browser or self-host. It aggregates public listings from itch.io, GitHub, Ludum Dare and Simple Game Tutorials.

Are the games really open source?

Yes. Every catalog entry carries a license — most are MIT, some vary (shown per card). OpenArc links directly to the source repository so you can audit, modify and redistribute the code.

Do I need to install anything?

No. Games run in the browser with plain HTML, CSS and JavaScript. There are no plugins, no downloads and no accounts.

Does OpenArc track visitors?

No. The site ships zero analytics, zero cookies and zero third-party trackers. Games execute locally in your browser.

Can I add my own game?

Yes. Add a static HTML file under play/ and append its metadata to data/games.json, then rebuild with scripts/build.py.

Which static hosts are supported?

Any host that serves files: Netlify, Cloudflare Pages, GitHub Pages, Vercel, S3 or a plain nginx folder. netlify.toml is included for Netlify.
